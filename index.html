DAY 03 / LESSON 01 · 개발·배포 준비

Git과 Node.js,
언제 필요할까요?

Antigravity로 홈페이지를 만들고 GitHub와 Vercel로 배포하기 전, 두 프로그램의 역할과 설치 시점을 알아봅니다.

Git은 코드의 변경 이력을 관리하고, Node.js는 JavaScript를 실행합니다.

홈페이지 제작에 함께 쓰이지만 설치하는 목적은 다릅니다.

역할 비교설치와 실행제작 방식별 준비수업 전 안내

1. Git과 Node.js의 차이

두 도구의 역할과 사용 시점
구분GitNode.js
핵심 역할코드의 변경 이력 관리JavaScript 실행 환경
주된 목적코드 저장, 버전 관리, 협업웹 개발 도구 실행 및 서버 개발
대표 활용변경 내용을 기록하고 GitHub에 코드 업로드React·Next.js 개발 프로젝트 실행
설치 시점로컬에서 버전 관리를 하거나 GitHub로 코드를 올릴 때프로젝트 실행에 Node.js가 필요할 때
필수 여부작업·업로드 방식에 따라 선택개발 기술과 실행 방식에 따라 선택

2. 실제 제작 과정에서는 언제 쓸까요?

  1. Antigravity로 제작홈페이지 코드 작성·수정
  2. 내 컴퓨터에서 실행React·Next.js 프로젝트는 Node.js 사용
  3. GitHub에 업로드Git으로 변경 이력 관리·전송
  4. Vercel로 배포배포 설정 후 공개 주소 확인

React·Next.js 기반 프로젝트의 일반적인 흐름입니다. 제작 기술과 배포 방식에 따라 필요한 도구가 달라집니다.

① Git · 코드를 기록하고 올릴 때

수정한 내용을 버전으로 기록하고 GitHub에 올릴 때 사용합니다. 어제 기록한 홈페이지가 더 좋았다면 그 버전을 확인하거나 복원할 수 있습니다.

Git은 내 컴퓨터의 버전 관리 도구, GitHub는 코드를 온라인에 보관하고 공유하는 서비스입니다.

Git 공식 다운로드 ↗

② Node.js · 프로젝트를 실행할 때

React나 Next.js 같은 개발 프로젝트를 내 컴퓨터에서 실행할 때 주로 필요합니다. Node.js를 설치하면 일반적으로 npm도 함께 설치됩니다.

Node.js 공식 다운로드 ↗

설치할 때는 LTS 버전을 선택하세요. 프로젝트에서 요구하는 버전이 있다면 그 조건도 확인합니다.

React 프로젝트 실행 예시

Antigravity에서 작업 중인 프로젝트 폴더의 터미널에서 순서대로 실행합니다.

npm install
npm run dev
  • npm install · 프로젝트에 필요한 패키지 설치
  • npm run dev · 개발용 웹사이트 실행

package.json에 dev 실행 항목이 있는 프로젝트의 예시입니다. 실행 후 터미널에 표시된 로컬 주소를 열어 확인하세요. HTML 파일만 사용하는 홈페이지에는 이 명령이 필요하지 않습니다.

3. 어떤 경우에 둘 다 설치할까요?

내 컴퓨터에서 작업할 때의 준비 기준
홈페이지 제작·작업 방식GitNode.js
HTML + CSS + JavaScript 기본 홈페이지선택별도 개발 도구가 없다면 불필요
React 홈페이지선택일반적인 로컬 개발에 필요
Next.js 홈페이지선택일반적인 로컬 개발에 필요
GitHub에 코드 업로드로컬 Git으로 올릴 때 필요업로드 자체에는 불필요
Vercel에 홈페이지 배포배포 방식에 따라 다름로컬 개발·빌드 방식에 따라 필요

GitHub 웹사이트에서 파일을 직접 업로드한다면 Git을 설치하지 않고도 사용할 수 있습니다.

4. Antigravity 교육 전 준비 안내

Antigravity로 홈페이지를 만들고 GitHub와 Vercel로 배포하는 수업에서는 Git과 Node.js를 수업 전에 설치하도록 안내하면 실습을 이어가기 편합니다.

이번 수업처럼 HTML·CSS·JavaScript로 만든 기본 홈페이지는 Node.js 없이도 확인할 수 있습니다. React·Next.js 프로젝트로 진행할 때는 Node.js 실행 환경을 준비합니다.

수강생에게 이렇게 설명하세요.

“Git은 홈페이지 코드의 수정 이력을 기록하고 GitHub에 올리는 도구입니다. Node.js는 React·Next.js 같은 개발 프로젝트를 내 컴퓨터에서 실행하는 환경입니다.”

설치가 되었는지 확인하기

설치 후 터미널을 새로 열어 아래 명령을 한 줄씩 입력하세요. 각각 버전 번호가 표시되면 실행할 수 있는 상태입니다.

git --version
node --version
npm --version

명령을 찾을 수 없다고 나오면 설치를 완료했는지 확인하고, Antigravity와 터미널을 다시 열어 보세요.
